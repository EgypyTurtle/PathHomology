# 用逐对代数 Morse 消去加速 path homology

日期：2026-10-19。本文对应 `core.py` 的可选 `homology_method="morse"` 后端及独立模块 `morse.py`。默认 `"linear"` 后端保留，用于兼容和交叉校验。

## 1. 先用一句话说明

**把链复形中不贡献同调的“可消去对”逐对移除，严格修正剩余边界，并记录剩余向量如何写回原始路径链。**

这不是数值近似，不是只猜 Betti 数，也不是在原图中随意删除顶点或边。我们缩减的是一个带基的链复形，其基向量可能是若干路径的线性组合。

本次使用代数 Morse 理论中的**可逆配对与初等链收缩**。每次在当前复形中配对一个高维基向量和一个相邻低维基向量，完成一次消去后重新选择。一般的代数 Morse 方法允许一次选择较大的无环匹配，并通过梯度路径求和计算新边界；本实现没有采用这种批量路径遍历算法，也不声称实现了最优匹配。理论背景见 Sköldberg 的[代数 Morse 理论及其链收缩表述](https://arxiv.org/html/1311.5803)，迭代缩减与计算背景见 Lampret 的[链复形缩减论文](https://arxiv.org/abs/1903.00783)。

## 2. 消去的对象是什么

设系数域为 K，有限链复形为

$$
\cdots\longrightarrow C_{p+1}\xrightarrow{d_{p+1}}C_p
\xrightarrow{d_p}C_{p-1}\longrightarrow\cdots,
\qquad d_{p-1}d_p=0.
$$

每个 C_p 已选定一组基。取 a∈C_p、b∈C_{p-1} 为基向量，设

$$d a=\lambda b+u,\qquad [b]u=0,\qquad \lambda\ne0.$$

记号 `[b]v` 表示向量 v 的 b 坐标。因为 K 是域，非零 λ 可逆。这个可逆连接使 a、b 可以被配对消去。但**不能直接删掉它们对应的一列和一行而不修正其余元素**。

对同维的其他基向量 x，令 c_x=[b]d x，作基变换

$$x'=x-\frac{c_x}{\lambda}a.$$

于是

$$d x'=d x-\frac{c_x}{\lambda}d a,$$

其 b 坐标恰好为零。因此删去 a、b 后，剩余边界的矩阵条目为

$$
D'_{r,x}=D_{r,x}-\frac{D_{b,x}D_{r,a}}{D_{b,a}},
\qquad r\ne b,\ x\ne a.
$$

这就是一次稀疏的 Schur 补消去。它在矩阵层面与精确高斯消元密切相关；代数 Morse 的关键是同时把它解释为**整个链复形的收缩**，而不只是某一个矩阵的秩计算。

### 一个具体例子

假设有两条有向边 a=(c,b)、x=(d,b)，它们的边界为

$$d a=b-c,\qquad d x=b-d.$$

将 a 与顶点基向量 b 配对。新的一维向量为 x'=x-a，边界变成

$$d x'=c-d.$$

原图未必存在 d→c 这条边；新向量实际代表原图中的链 `(d,b)−(c,b)`。因此不能把此操作简单理解为“把原图的一条边换成另一条边”。

## 3. 为什么同调严格保持不变

以下给出单次消去的可核查恒等式，避免仅凭直觉说“删去不重要的部分”。

令 U 是移除 a、b 后剩余基向量张成的分次向量空间，j:U→C 为坐标包含，π:C→U 为坐标投影。先定义升维映射 h：

$$h(b)=\lambda^{-1}a,\qquad h(y)=0\quad(y\ne b).$$

定义新的边界、提升映射和投影映射：

$$
d'=\pi(d-dhd)j,\qquad
I=(1-hd)j,\qquad P=\pi(1-dh).
$$

直接利用 d²=0 与 hdh=h，可验证

$$
d'^2=0,\quad dI=Id',\quad Pd=d'P,\quad
PI=1_U,\quad 1_C-IP=dh+hd.
$$

最后一个式子说明 IP 与恒等映射链同伦。若 z 是闭链，则

$$z-IPz=d(hz),$$

所以 z 与 IPz 只相差一个边界，代表同一个同调类。结合 PI=1，可得

$$H_p(C,d)\cong H_p(U,d')\quad\text{对每个 p 成立。}$$

本文使用 `1−IP=dh+hd` 的符号约定；部分参考文献将 h 换成 −h，写成 `IP=1+dh+hd`，两者等价。

每一步都作用在**更新后的**复形上。单对匹配不存在匹配反向后的有向循环，因此可逐步应用初等代数 Morse 收缩，并复合得到原复形与最终复形的链同伦等价。无需假设所有在原矩阵上挑选的配对合在一起仍然无环。

在有限维的域上，只要剩余边界还有非零元素，就能继续消去。每步使总链空间维数减少 2，因此最终边界全部为零。此时最终剩余的 p 维基向量恰好给出 H_p 的一组基。注意：**一般的单轮 Morse 匹配不保证新边界为零；这里是反复消去直到无非零边界为止。**

## 4. 怎样用于当前的 path homology

### 4.1 必须先得到真正的链复形 Ω_*

允许 p-path 张成的空间记为 A_p。其形式边界可能含不允许的面，因此通常

$$\partial A_p\not\subset A_{p-1}.$$

这意味着不能直接把“允许路径之间的部分边界矩阵”当作链复形做 Morse 消去。正确对象为

$$\Omega_p=\{v\in A_p:\partial v\in A_{p-1}\},\qquad
d_p=\partial|_{\Omega_p}.$$

由 ∂²=0 得到 ∂Ω_p⊂Ω_{p-1}，所以 Ω_* 确实是链复形。

本轮保留前几轮的 Ω 求解：支撑剪枝、约束核计算及规范基恢复都不变。**没有声称 Morse 已经消除了 Ω 构造的成本。** 当前加速位置是 Ω 得到之后的链微分、闭链、边界和同调代表元计算。

### 4.2 不先构造大块 Python 对象矩阵乘积

旧完整后端主要执行：

1. 用稠密的允许路径边界矩阵乘 Ω 基矩阵；
2. 换到下一维 Ω 基的坐标；
3. 求各个 d_p 的核；
4. 对 `[边界生成列 | 闭链基]` 再做消元，以选取商空间代表元。

Morse 后端改为逐个读取 Ω 基向量的**非零路径项**，直接累加其形式边界。非允许面的系数必须全部抵消，程序对此作检查。然后读取 Ω_{p-1} 规范核基上的单位坐标行，获得 d_p 的稀疏列；若某个替代基不具备单位坐标行，则回退到已有的精确换基求解。

最后以稀疏字典保存微分及原坐标提升，执行上述逐对消去。F₂ 上用非零项的切换实现加减；一般 F_p 使用整数模运算，Q 上保持精确整数/有理数。这样绕开许多对零元素的对象访问、对象数组类型扫描与稠密乘法。

本次实测的加速是**链收缩与稀疏实现共同产生的结果**，不能全部归因于抽象 Morse 定理；也没有把旧后端已有的“用于求秩的单项行列剥离”重新命名为 Morse 方法。

### 4.3 怎样恢复原始路径上的代表元

程序为当前每个基向量维护到原 Ω 坐标的提升 L。初始 L 为恒等映射。消去时同步更新

$$L(x')=L(x)-\frac{c_x}{\lambda}L(a).$$

所有微分最终为零后，剩余基向量通过 L 变回原 Ω 的闭链，再通过原 Ω 基展开为 `{原始路径: 系数}`。因此用户拿到的不是无法解释的抽象“临界点”，而是可直接检查边界为零的原图路径链。

此外，每次消去 a∈C_p、b∈C_{p-1} 时保存原坐标边界 L(d a)=d_original L(a)。每个这样的对贡献一个独立的 (p−1) 维边界方向。所有保存的边界构成 B 的基；它们与最终提升的 H 代表元合在一起构成 Z 的基。

独立性的依据不是“它们都非零”，而是每次基变换都分离出一个两项可收缩直和分量。递归展开这些直和分解，得到互相独立的已消去边界方向和最终临界方向。

设 m_p 是在 C_p→C_{p-1} 中消去的对数，则

$$
\operatorname{rank}d_p=m_p,\qquad
\dim Z_p=\dim\Omega_p-m_p,\qquad
\dim B_p=m_{p+1},\qquad
\beta_p=\dim\Omega_p-m_p-m_{p+1}.
$$

这里 Ω、Z、B 的维数仍指**原复形**，不会错误地用缩减后临界空间维数代替 Ω 的维数。

实现保存所需的提升和边界链，不显式物化完整 P 和 h 矩阵；这些映射的存在及公式用于正确性证明。测试会逐步构造它们并验证链收缩恒等式。

### 4.4 消去顺序与工程策略

从低维向高维处理 d₁、d₂、……。优先考虑短列，并在其中优先选关联列数少的行，减少新非零元素的产生；这是启发式而非全局最小填充保证。

处理 d_p 时，d_{p-1} 已为零。消去后，d_{p+1} 中被移除的 a 坐标在新基下为零，理由是 d_p d_{p+1}=0。因此可移除对应行，而无需对相邻矩阵执行大块稠密基变换。这一步依赖链条件，不能对任意互不相关的矩阵照搬。

## 5. 系数范围和不能越界的地方

本后端支持 Q 和任意程序所接受的素数域 F_p，**不局限于 F₂**；并非实现了任意系数环或任意扩域。浮点 R 不走此精确后端。

“非零即可消去”依赖于域。若在整数上有 d a=2b，2 不是可逆元，直接消去会丢失挠信息；在 Q 上它可消去；在 F₂ 上该边界变为零，反而不能作该配对。程序必须在用户指定的系数域上独立运算，不能把 Q 上的配对序列原样套到 F₂。

当前保证普通 path homology 的链同伦等价，不自动保证以下对象保持不变：

- **Persistent path homology**：还须让收缩与过滤及结构映射兼容；每个时间点分别同调相同不够。本轮未修改 persistent。
- **原始内积下的 Laplacian 谱**：I 一般不是等距映射；同调等价只保证同调维数，不能直接保留原始非零特征值或谐波向量。本轮未修改 laplacian，它仍使用原有 gen5 核心。
- **原有代表元的逐项相同**：Morse 模式的 Z/B/H 基通常与默认模式不同，但定义相同子空间和商空间。Ω 规范基保持不变。Morse 的 `boundaries[p]` 是独立基，默认模式则可能含冗余边界列。

## 6. 如何使用

需要显式路径链代表元，且不需要额外的稠密允许路径边界矩阵时：

```python
from core import path_homology

k = 2  # 想求 H_0,...,H_2
r = path_homology(
    vertices, edges,
    max_dim=k + 1,       # H_k 还需要 Omega_(k+1) 的边界
    field="Q",          # 也可使用 2、3、5、101 等素数
    loops=False,
    regular=False,
    homology_method="morse",
    generators=True,
    store_matrices=False,
)
print({p: r.betti[p] for p in range(k + 1)})
print(r.homology_basis[1])  # 原始路径坐标下的闭链
print(r.morse_stats)       # 配对数、填充数、最终临界维数等
```

若还要原先的稠密 `boundary_matrices`，改为 `store_matrices=True`，或不指定此参数。`store_matrices=False` 不改变数学问题和代表元输出，但明确省略这份附加矩阵；不能把省掉该输出所带来的内存收益全部当成消去算法收益。

只求 Betti 数时仍推荐已有的稀疏维数路线：

```python
r = path_homology(vertices, edges, max_dim=k+1, field="Q", loops=False,
                  generators=False, store_paths=False)
```

这一模式避免构造 Ω 的显式基。本次 Morse 后端不强制替换它，并拒绝 `homology_method="morse", generators=False` 的组合，以免误导用户把较贵的显式基路线当成新的维数快路。

无向循环对应的有向循环等图，需要明确有限 `max_dim`。在截断最高维上返回的同调是截断复形的同调；要讨论原图的 H_k，必须至少计算到 k+1，或另有 Ω_(k+1)=0 的严格依据。

## 7. 复杂度与效果边界

设某次配对的非零列长为 c、该配对行的非零列数为 r。仅 Schur 补更新最多涉及约 `(r−1)(c−1)` 个候选条目；还须计入提升向量的更新、边界输出与堆维护。Q 上还要计入分子分母的位数增长，不能只用域运算次数代表全部成本。

本实现为维护双向行列索引，还会扫描受影响列的旧、新支撑，因此实际成本也包含这些列的支撑大小之和，并非严格只有上述乘积项。

稀疏局部结构下，消去可以显著减少后续工作；但消去也可能产生填充，代表元本身可能很长。**不保证任意输入都更快，不声称总体线性复杂度，也没有突破允许路径数随维度指数增长的上界。** Ω 的基构造和稠密公开 Ω 矩阵仍可能成为瓶颈。

具体测速、重复次数、资源限制和版本哈希另见 `MORSE_PERFORMANCE_20261019.md`；理论说明与机器测量分别记录，避免把数学保证和经验性能混在一起。

## 8. 本次正确性验证的内容

`test_morse.py` 不只比较 Betti 数，还包括：

- 对 50 个 Q/F₂/F₃/F₅/F₁₀₁ 上的有限链复形，逐次验证 PI=1、1−IP=dh+hd、I/P 是链映射以及 d'²=0；最终提升也与逐步复合的 I 比较。
- 对三顶点无自环有向图的 64 种边集，在 regular/non-regular、Q/F₂/F₃/F₅ 下交叉检查，共 512 组。
- 另加 60 组随机图（包含自环、高至四维、F₁₀₁）和空图/孤立顶点等边界情况，共 575 组 path complex 检查。
- 验证 Ω 基保持不变，Z/B/H 返回链均属于原始允许路径空间，闭链的完整形式边界为零；以精确秩验证 B 的张成空间、Z 的独立性及 H 在模 B 后的独立性。
- 检查系数特征导致的不同消去，以及拒绝非链复形输入（检查模式）、浮点或不支持的选项组合。

这些是有限样本的实现验证；对一般输入的数学依据是第 3 节的链收缩恒等式，而不是测试数量本身。
