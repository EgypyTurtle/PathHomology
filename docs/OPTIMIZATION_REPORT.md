# Path homology 代码审查与优化报告

## 1. 最小可计算代码组

真正完成 GLMY path homology 计算的是 `core.py`，运行时只依赖
NumPy 和 Python 标准库。

- 最小单文件用法：`core.py` + NumPy，使用
  `from core import path_homology`。
- 标准包用法：再加 `__init__.py`，使用
  `from path_homology import path_homology`。本次已将其修正为包内相对导入。
- 需要命令行时再加 `cli.py`。
- `test_path_homology.py`、`test_fields.py`和新增的
  `test_optimization.py` 是验证代码，不是计算引擎的运行时依赖。
- `pn_*`、`dm_*`、`dmn_*`、`snf_*`、`check_*`、`verify_*`、
  `bench_*`和 `profile_*` 是特定图族研究、整系数同调、审计、基准或报告脚本，
  不属于最小通用实现。

## 2. Omega_n 的组合优化

`allowed_paths` 的逐层扩展本质上是枚举有向 walk。如果 API 要返回全部
`A_p` 的基以及生成元，这部分的输出规模本身就可能是指数级，不存在
对所有图都有效的无损剪枝。本次对它做了一个重要的安全优化：在扩展前
先去重输入边，避免重复边的数量在高维被指数放大。

原默认 `kernel` 方法的额外 BFS 则不是必需的。一个约束行只有在它真的是
某个允许 p-路径的不允许边界面时才可能出现。现在的实现直接扫描每个
允许 p-路径的 p+1 个面，将不在 `A_{p-1}` 中的面分组成约束矩阵。
因此约束构造成本是

`Theta((p+1)|A_p|)`，

而不再依赖边与半边联合关系中所有候选 walk 的数量。`lemma41`
也改成对实际边界面做相同的直接分组；`prop42` 改为单次扫描
`A_2`，不再对每条半边重扫全部 2-路径。

一个专门压力测能清楚显示剪枝效果：对 40 个顶点的单向链，计算
`Omega_15` 时 `|A_15|=25`。旧算法构造了 `311270 x 25` 的约束矩阵，
其中绝大多数是永远不会被边界命中的零行，用时 1.982 s；新算法只保留
`350 x 25` 的实际约束，用时 0.013 s，约快 154 倍，两者得到相同的
`dim Omega_15=0`。

## 3. 线性代数优化

原实现将 `Fraction` 和 `GF` 元素放在 `dtype=object` 的 NumPy 矩阵中。
NumPy 对这种矩阵乘法会回到 Python 对象运算，导致大量 `GF.__mul__`、
`GF.__add__` 和 `Fraction` 调用。现在：

1. 所有素数域 `GF(p)` 都转成整数 NumPy 数组做模 p 消元、零空间、
   秩、pivot 列和矩阵乘法，再转回兼容原 API 的 `GF` 对象。
2. 对系数在 `Q` 上但实际为整数、且可证明不会溢出 int64 的矩阵乘法，
   使用原生 int64 内核；真正的分数数据仍回退到精确 `Fraction`。
3. `_nullspace` 生成的规范基在自由坐标上含单位块。因此将向量表示到
   `Omega_{p-1}` 基中时，可以直接抽取相应行，通常无需新的高斯消元。
4. 周期、边界和同调代表元从 Omega 坐标展开到允许路径坐标时，
   由“每列一次矩阵乘法”改为“每个维度整批一次”。
5. 有限域的全零矩阵现在也保留域信息，避免因首个元素恰好是普通整数 0
   而错过快速路径。

在同一台机器、完全 DAG `N=9, max_dim=5` 上的端到端实测：

| 系数 | 优化前 | 优化后 | 加速 |
|---|---:|---:|---:|
| `GF(2)` | 8.633 s | 0.081 s | 107x |
| `Q` | 10.906 s | 0.710 s | 15x |

这个基准中 `dim Omega_p=(9,36,84,126,126,84)`。优化后的 `GF(3)` 和
`GF(5)` 在同一任务上分别约为 0.090 s 和 0.093 s。

## 3.1 第二轮线性代数与稀疏优化

进一步剖析后又完成了以下优化：

1. 有理数秩和零空间先逐行清除分母，然后用本原整数行做无分数消元；
   只在最后回代零空间基时使用 `Fraction`。它仍然是严格精确算法。
2. 对每个微分 `d_p` 只求一次零空间，再由秩–零化度定理得到秩，
   删除同一矩阵的第二次消元。
3. 显式识别 `Omega_p=A_p` 的情形，直接复用边界矩阵和已有坐标，
   不再反复扫描单位矩阵。
4. 新增 `generators=False` 维数快速模式。设 `C_p` 为不允许边界面约束，
   `F_p` 为允许 p-路径的完整边界，则

   `dim Omega_p = |A_p| - rank(C_p)`,

   `dim Z_p = |A_p| - rank(F_p)`,

   `dim B_p = dim Omega_{p+1} - dim Z_{p+1}`.

   因此只求维数和 Betti 数时，完全无需构造 Omega 基、基变换和代表元。
5. 该模式不再构造稠密边界矩阵。每个边界行以非零列字典保存；
   `F_2` 的行进一步压成 Python 大整数位集，用大整数 XOR 消元；
   `Q` 使用稀疏本原整数消元。

同一个 `N=9, max_dim=5` 完全 DAG 的第二轮结果是：

| 模式 | `GF(2)` | `Q` | 相对最初版 |
|---|---:|---:|---:|
| 最初版 | 8.633 s | 10.906 s | 1x |
| 完整生成元输出 | 0.037 s | 0.106 s | 235x / 103x |
| 稀疏维数模式 | 0.0010 s | 0.0063 s | 8200x / 1700x |

在 `N=15, max_dim=6` 的完全 DAG 上，其中 `|A_6|=6435`，稀疏维数模式
计算 `GF(2)` 约需 0.067 s，精确 `Q` 约需 5.62 s，而且不需要保留任何
`|A_{p-1}| x |A_p|` 稠密矩阵。

## 3.2 第三轮：可证明的模秩证书与批量精确回代

第三轮剖析显示，第二轮的精确 `Q` 稀疏消元仍会产生数千万次字典查询。
本轮加入以下优化：

1. 对整数矩阵先计算模 2 秩。模 2 秩是有理秩的严格下界；若它达到
   `min(非零行数, 列数)`，即可无条件证明有理秩，不再运行整数消元。
2. 当所有边界面仍然允许时，利用链条件
   `im(partial_p) subset ker(partial_(p-1))` 给出更紧的有理秩上界。
   模 2 下界达到该上界时同样得到严格证书。若没有达到，仍回退到原来的
   精确无分数整数消元，因此这不是概率算法。
3. 一维边界矩阵直接使用图关联矩阵定理
   `rank(partial_1)=|V|-弱连通分支数`。
4. 稀疏行消元改为原地合并非零项，删除反复构造键集合和多次字典查询。
5. 精确零空间的所有自由变量同时回代，跳过自由变量单位块中大量必为零的
   检查；输出仍是相同的规范自由变量基。
6. `GF(2)` 在中小宽度直接生成大整数位行；超宽矩阵自动切回稀疏字典后
   一次性打包，避免反复复制越来越大的 Python 整数。

同机复测：

| 任务 | 第二轮 | 第三轮 | 本轮加速 |
|---|---:|---:|---:|
| `N=15, max_dim=6, Q` 维数模式 | 3.65 s | 0.092 s | 39.6x |
| `N=11, max_dim=6, Q` 完整生成元 | 3.57 s | 1.21 s | 2.9x |
| 含环随机图（949 个四路径），`Q` 维数模式 | 0.422 s | 0.221 s | 1.9x |

在 `N=15` 的完全 DAG 上，第三轮精确 `Q` 维数模式已与 GF(2) 处于同一
数量级。所有快速返回都有上下界相等的数学证书，不能证明时会自动走精确
回退路径。

## 4. 系数域的实际支持范围

核心并非只实现 `F_2`。它支持：

- `field="Q"`：精确有理数，默认选项；
- `field=2`, `"Z2"`, `"GF2"`, `"F2"`：`F_2`；
- `field=p`：任意素数 p 的素域 `F_p`；
- `field="R"`：浮点近似实数线性代数。

本次补上了素性验证：原代码会接受 `field=4`，但 `Z/4Z` 不是域，
使用 Fermat 形式的“求逆”会得到错误结果。现在合数模会被明确拒绝。

“任意系数”如果指任意域，目前仍不包括任意域扩张、代数数域或用户自定义域；
如果指任意环，则核心 API 也不支持。特别是整数系数 `Z` 下的扭结不能用
普通域上的 rank/nullspace 得到；目录中的 `pn_integral.py`、`h1_integral.py`、
`snf_robust.py` 等是另行的 Smith 标准形研究脚本，尚未并入通用核心。

系数特征确实会改变答案。例如代码中的 `P_2` 图族成员：

- `dim H_1(P_2; Q)=1`；
- `dim H_1(P_2; F_2)=2`；
- `dim H_1(P_2; F_3)=dim H_1(P_2; F_5)=1`。

这与整系数同调中的 2-扭结一致，也说明 `F_2` 不只是一个可互换的加速选项。

## 5. 验证与使用边界

- 原有 21 组数学回归测试全部通过。
- 在 12 个固定随机图上，对 `Q, F_2, F_3, F_5` 逐一与优化前实现比对，
  `dim Omega`、周期维数、边界维数和 Betti 数全部一致。
- 另外验证了 `GF(2), GF(3), GF(5), GF(101)` 的原生模矩阵乘法、重复边去重、
  合数模拒绝及上述系数依赖例子。

最后要注意截断：对有向环图，允许路径在任意维度都可能存在。
`max_dim=D` 计算的是截断复形，顶维 `H_D` 将忽略来自 `Omega_{D+1}` 的边界。
因此要得到 `H_k` 至少必须构造到 `Omega_{k+1}`，并结合问题本身判断更高维
是否会继续影响结果。
